# Public Reproducibility Results

## Official upstream smoke demo

The committed public result was generated by `scripts/run_public_demo.py` using
the official VoxelMorph example atlas and test scan together with the verified
pretrained model. Provenance and computed metrics are stored in
`reports/public_demo/public_demo_metrics.json`.

The demo confirms that the environment can load the pinned model, perform one
forward pass, return a moved image and final full-resolution warp, transform the
public label map, and compute finite metrics. It does not validate anatomy,
clinical performance, a population, or controlled-access data.

## Synthetic regression tests

Synthetic tests verify that integer quantization, sparse output, constant data,
and non-finite values are detected without using medical images. Additional
tests verify that moved-image and warp outputs are obtained from a single graph
prediction with the expected shapes.

## Public-data validation

Four public T1-weighted scans from OpenNeuro `ds005125` v1.0.0 were each
registered to the atlas. Inputs were reoriented from their affines, linearly
resampled to the atlas grid, converted to `float32`, and robustly nonzero
min-max scaled to `[0, 1]`. The table is transcribed from the committed
[metrics JSON](../reports/public_validation/public_validation_metrics.json).

See the [validation figure](../figures/public_validation/public_validation_metrics.png)

This four-scan experiment validates software and method execution only. It has

anatomical segmentation accuracy. It supports no clinical, biological, or
population-level conclusion.

## Controlled-access observation boundary

The dtype failure was initially identified during controlled-access imaging
work. The public repository retains the technical mechanism and reusable
quality controls, but does not publish participant-level reports, numerical
results, longitudinal comparisons, images, or derived artifacts from that work.

## Interpretation limits

- Public-example performance is not clinical validation.
- Intensity-derived foreground-mask Dice is not anatomical-label Dice.
- Positive Jacobians alone do not establish registration correctness.
- Warp differences are not measurements of atrophy or biological change.
- No diagnostic or population-level conclusion is supported.
